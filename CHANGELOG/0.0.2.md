## Audio XAI 0.0.2

```sh
uv add Audio-XAI
```

### Models

- **AST (Audio Spectrogram Transformer):** binary real/fake classifier with configurable `clip_seconds`; position embeddings automatically sized to match clip length, making 5 s clips feasible on a 40 GiB A100
- **VGGish:** official architecture alignment with TF1 checkpoint loading; long audio tiled into patches with averaged logits
- **Sonics (SpecTTTra):** HuggingFace-hosted model integrated into predict and attack pipelines

### Attack

- Perceptual XAI attack that flips Grad-CAM explanations while preserving predictions and staying below the psychoacoustic masking threshold
- Full-audio sliding-window mode (`--full-audio`, `--window-hop-seconds`) — attacks the entire waveform and stitches per-window deltas
- Migrated from a manual for-loop to **Lightning Trainer** (`AttackModule`) — SLURM-aware, automatic GPU management, TensorBoard integration
- Configurable micro-batching (`--attack-micro-batch`) for GPU memory control
- **Resume support:** skips already-processed samples on resubmit by checking for existing `audio/*/adversarial.wav` outputs
- Batched runs via `--n-batches` / `--batch-index` — all batches share one `--run-name` output directory
- OOM retry loop with exponential backoff; samples skipped after max retries

### Data

- `SonicsDataset` / `SonicsConfig` — binary real/fake loader supporting both directory layout and CSV files
- Pre-split CSVs (`train.csv`, `valid.csv`, `test.csv`) included
- `--train-csv` / `--val-csv` flags in training script for pre-balanced splits
- Balanced sampling (equal real/fake) in predict and attack scripts

### Training

- Multi-node SLURM training via Lightning `SLURMEnvironment` with auto-requeue
- YAML config support with CLI override (`--config config/train_ast.yaml`)
- Stratified train/val split with inverse-frequency class weights
- `_TBLogger` suppresses Lightning's auto-logged `epoch` scalar for cleaner TensorBoard

### Metrics

- **EER:** replaced 1000-threshold grid loop with vectorised sort sweep — O(N log N) instead of O(N·T)
- **Psychoacoustic masking:** replaced `[B, n_freq, n_freq, n_frames]` tensor (165 GB at B=1000) with a memory-safe per-masker loop
- PESQ, STOI, ViSQOL, PEAQ, CDPAM all wired into attack output
- CPU metrics (PESQ, STOI, ViSQOL, PEAQ) parallelised via `ThreadPoolExecutor`

### Infrastructure

- Audio loading migrated from `librosa` to `torchaudio` throughout (differentiable, no numpy round-trip)
- All SLURM sbatch scripts for train / predict / attack under `sbatch/`
- `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` set globally to reduce GPU memory fragmentation
